# Signaldesk

这是一个概念项目，用来做加密货币量化。最新新闻、社区讨论和链上大额转账提供外部信号，辅助判断要不要交易、交易什么；币安行情和账户负责定价、看仓位和执行。信号和执行按这个分工设计，目前还没有接成自动闭环，不能当可上线的机器人用。

`src/user/order.py` 会打币安合约实盘。

## 架构

**信息，辅助决策**

- `src/radar/twitter.py`：按关键词收集近期推文，当作最新消息来源。`main.py` 只启动这一路。
- `src/radar/reddit.py` 和 `src/strategy/reddit.py`：拉板块帖子，再用 GPT 看情绪、影响和可信度，筛掉低价值内容。
- `src/radar/chain_warning.py`：盯以太坊上的大额转账，作为资金异动信号。
- `src/radar/x.py`：用浏览器抓 X 搜索页，只是实验。

**行情与执行**

- `src/markets/`：查价格、精度、杠杆和盘口深度，给下单和仓位判断提供市场数据。
- `src/user/`：查资产，设置杠杆和保证金模式，并下单。
- `src/utils/`：读密钥、给私有接口签名，并缓存精度和杠杆。


密钥写在 `.env` 里，这个文件不会提交。字段说明见 `.env.example`。
